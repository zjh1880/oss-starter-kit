# Change log

English | [中文](./CHANGELOG.zh.md)

All notable changes to this project will be documented in this file.

## [1.1.0] - 2026-06-11

### Added

- `loadConfig(options)` for normalized project configuration.
- `validatePackageMetadata(metadata)` for release readiness checks.
- `buildProjectManifest(options)` for package.json scaffolding.
- `createReleaseNotes(version, changes)` for repeatable release notes.
- `describeProject(options)` for concise project summaries.
- Additional public API tests and examples.

## [1.0.0] - 2026-06-11

### Added

- Zero-dependency Node.js package skeleton.
- Built-in Node.js tests.
- GitHub Actions CI workflow.
- Contributor, security, support, and code of conduct docs.
- Issue and pull request templates.
- Architecture and release guides.
- Example usage.
